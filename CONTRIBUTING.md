# Contributing

Thanks for wanting to help with Voice!

- **Found a bug?** [Open a bug report](https://github.com/PaulWoitaschek/Voice/issues/new?template=bug.yml) with steps to reproduce.
- **Have an idea?** [Open a feature request](https://github.com/PaulWoitaschek/Voice/discussions/new?category=ideas). Describe the problem you want solved, not only the solution.

Search the existing [issues](https://github.com/PaulWoitaschek/Voice/issues) and [discussions](https://github.com/PaulWoitaschek/Voice/discussions) first and upvote what's already there.

## Pull requests

Voice only accepts pull requests I asked for. I don't have the time to review outside code, and it's fairer to say so than to let pull requests go stale.
